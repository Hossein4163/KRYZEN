Read before creating or changing any project.\n---\n\n# Project standards\n\nEvery project lives in `~/Projects/devpilot/<slug>/` and is created **only** with the `project_init`\ntool (never by hand). It copies the standard template, runs `git init` and registers the project\nin `~/Projects/devpilot/INDEX.md`.\n\n## Layout and ownership\n```\n<slug>/\n├── README.md              Build Agent: how to install, run, build, test (keep commands real)\n├── PROJECT.md             Orchestrator: spec, status, phase checklist, log table\n├── CHANGELOG.md           Build Agent: one entry per milestone under [Unreleased]\n├── .gitignore\n├── .devpilot/\n│   ├── STATE.json             Save Checkpoint tool: phase, next_action, history (resume point)\n│   └── journal.jsonl          bridge: automatic log of every action (git-ignored)\n├── docs/\n│   ├── research/BRIEF.md          Research Agent\n│   ├── references/REFERENCES.md   Reference Agent (+ images/ for screenshots)\n│   ├── design/DESIGN.md           Orchestrator / Build Agent: tokens, type, spacing\n│   ├── plan/PLAN.md               Planner Agent: acceptance criteria, architecture, tasks, test plan\n│   ├── decisions/NNNN-title.md    anyone: one ADR per significant decision (0001-tech-stack.md first)\n│   └── qa/REPORT.md               QA Agent (+ screenshots/<run>-<page>-<width>.png)\n├── src/                   application code\n├── public/                static assets\n└── tests/                 automated tests\n```\nNever put code in `docs/` or docs at the project root (other than README, PROJECT, CHANGELOG).\n\n## Scaffolding into an existing project folder\nScaffolders refuse non-empty folders, so scaffold into `.scaffold/` and merge without overwriting docs:\n```sh\ncd ~/Projects/devpilot/<slug>\nnpm create vite@latest .scaffold -- --template vanilla-ts   # or react-ts, vue-ts, svelte-ts…\ncp -rn .scaffold/. . && rm -rf .scaffold\n```\nThen clean leftovers: set `\"name\"` in package.json to the slug, delete demo files and assets\n(`counter.*`, `hero.png`, `vite.svg`, `typescript.svg`, `javascript.svg`, demo CSS), remove commented-out code,\nand replace the template README sections with real commands.\n\n## Conventions\n- **Slug**: lowercase kebab-case, 2–49 chars (`habit-tracker`).\n- **Commits**: Conventional Commits — `feat:`, `fix:`, `chore:`, `docs:`, `test:`, `refactor:`. Commit after each phase.\n- **PROJECT.md status** values: 🟡 intake · 🔵 research · 🟣 design · 📐 plan · 🟠 build · 🧪 qa · 🟢 done · 🔴 blocked.\n  Update the Status row, tick the phase checklist, and add a Log row `| date | agent | entry |` for each milestone.\n- **INDEX.md**: update the project's Status cell when the status changes.\n- **Dates**: always use today's date from your system prompt.\n- **Screenshots**: `docs/qa/screenshots/<run>-<page>-<width>.png`, e.g. `r1-home-390.png`.\n- **No secrets** in any file; use `.env` (git-ignored) and commit an `.env.example`.\n", "other_files": ["SKILL.md"]}
