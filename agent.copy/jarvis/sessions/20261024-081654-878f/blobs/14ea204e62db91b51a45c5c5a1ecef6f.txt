RTL rules\n470\t\n471\t1. **`dir` attribute:** `<html dir=\"rtl\" lang=\"fa\">` for Persian (default), `<html dir=\"ltr\" lang=\"en\">` for English. Set in root layout based on active locale; never hardcode `dir=\"ltr\"`.\n472\t2. **Logical CSS properties:** Use `margin-inline-start/end`, `padding-inline-start/end`, `inset-inline-start/end`, `text-align: start/end`, `float: start/end` instead of left/right equivalents. Tailwind logical variants: `ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`.\n473\t3. **Sidebar stays left:** The fixed left sidebar (256px desktop, ~72px collapsed) remains on the left in both `dir=\"rtl\"` and `dir=\"ltr\"` (per Vitrea design decision). Only internal alignment (icon position, text alignment, submenu direction) mirrors.\n474\t4. **Text alignment:** Headings, labels, and body text use `text-align: start` (right in RTL, left in LTR). Numeric data and right-aligned columns in tables use `text-align: end`.\n475\t5. **Mirrors:** Borders that were on the right (e.g., sidebar right border) stay on the right in both locales per Vitrea; padding/margin values mirror via logical properties.\n476\t6. **Typography:** Vazirmatn for Persian script, Inter for English. Font-family chain: `Vazirmatn, Inter, system-ui, sans-serif`. Self-host both with `@font-face` and `font-display: swap`.\n477\t7. **Numbers:** Persian locale uses Arabic-Indic digits (۰-۹) for display; English uses ASCII digits. Dates: Jalali (Shamsi) calendar for `fa`, Gregorian for `en`.\n478\t8. **RTL testing:** Every dashboard page (admin, customer, team) must be visually QA'd in both `dir=\"rtl\"` and `dir=\"ltr\"`; no broken alignment, no overflow, no misplaced icons.\n479\t9. **RTL overrides in Tailwind:** Add `[dir=\"rtl\"]` variants in `tailwind.config.ts` for any component that needs explicit RTL adjustments beyond logical properties.\n480\t\n481\t---\n482\t\n483\t## 8.
