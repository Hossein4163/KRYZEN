Tailwind v4 emits both `backdrop-filter` and `-webkit-backdrop-filter` automatically; `bg-*` opacity compiles to `color-mix()`.\n14\t- **Compatibility with Antigravity UI + Tailwind CSS 4:** Antigravity UI is a Tailwind-based component system (utility-first, no hard-coded opaque fills), so glass utilities compose directly on its components. Tailwind v4's `supports-[backdrop-filter]:` variant provides solid-fill fallbacks for browsers without `backdrop-filter`; avoid nesting glass inside glass (inner panel can only blur the outer panel's contents).\n15\t- **Accessibility:** check contrast over the *effective* surface color (not just the fill) — a 60% white fill over violet can yield ~4.0:1, failing 4.5:1 for body text; use darker text or raise opacity. Support `prefers-reduced-transparency` (custom Tailwind variant) and `prefers-contrast: more` (`contrast-more:` variant); add `scroll-padding-top` for sticky glass headers so focused elements stay visible; never animate `backdrop-filter` radius itself.\n16\t- **Performance:** `backdrop-filter` recomputes whenever content behind the panel changes (scrolling under sticky headers). One header/card is fine; many glass panels, very large panels, or animating blur radius cause jank on low-end phones. Reduce glass surface count before reducing blur radius; avoid `backdrop-filter`/`opacity` on `<body>` or page wrappers (blocks child blur).\n17\t- **Recommended stack:** Tailwind CSS 4 (native `backdrop-blur-*`, `supports-[backdrop-filter]:`, `color-mix()` opacity) + Antigravity UI components + custom `glass` design tokens in `tailwind.config.js`/CSS variables + React 19 components with `prefers-reduced-transparency`/`prefers-reduced-motion` guards + optional `@yhooi2/shadcn-glass-ui` for pre-built glass primitives.\n18\t\n19\t---\n20\t\n21\t## Glassmorphism CSS Techniques\n22\t\n23\t### Core glass surface recipe (Tailwind v4)\n24\t\n25\t```tsx\n26\t<div className=\"rounded-2xl border border-white/20 bg-white/60 p-6 shadow-lg backdrop-blur-lg backdrop-saturate-150\">\n27\t  {/* content */}\n28\t</div>\n29\t```\n30\t"}
