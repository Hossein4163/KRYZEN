UI Styling is a companion skill for React developers who want an agent to build interfaces with shadcn/ui, Tailwind CSS, dark mode and theming. It adds reference guides, two small Python helpers and a set of fonts for canvas poster designs. How to use UI Styling ? In a React project (Next.js, Vite, Remix or Astro) ask for a component or layout in plain words; the agent uses the guides and can run shadcn_add.py to add components. To set up Tailwind from scratch, tailwind_config_gen.py writes a tailwind.config file.
