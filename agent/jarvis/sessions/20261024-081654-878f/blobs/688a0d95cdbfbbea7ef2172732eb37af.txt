project deliverables be stored locally (Docker volume) or in S3-compatible object storage (MinIO locally)? Local is simpler for M1–M7; object storage is more production-realistic.\n178\t2. **SignalR auth:** SignalR hubs need JWT auth via query string or access token in the connection URL — confirm cookie-based session works if the frontend is served from a different origin.\n179\t3. **Calendar library depth:** Does shadcn/ui Calendar (Base UI) suffice for team month/week views with drag-to-reschedule, or is FullCalendar needed?\n180\t4. **Deployment target:** Is the production target a VPS (Docker Compose) or a PaaS?
